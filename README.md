# تطبيق مستشار نفسي (نسخة أولية)

هذا المشروع يحتوي على تطبيق موبايل أولي باستخدام **Expo + React Native** لفكرة:
- رفع محتوى ملفات الاستشارات النفسية كنص
- سؤال المساعد الذكي
- الحصول على إجابة مبنية على المحتوى الذي تم رفعه

## مكان التطبيق
- `/home/runner/work/aaaaa/aaaaa/mobile-app`

## التشغيل
1. ادخل مجلد التطبيق:
   - `cd /home/runner/work/aaaaa/aaaaa/mobile-app`
2. شغّل التطبيق:
   - `npm start`
3. افتح التطبيق على الهاتف عبر Expo Go أو على محاكي.

## ملاحظات
- النسخة الحالية MVP وتستخدم بحثًا نصيًا محليًا بسيطًا.
- لاحقًا يمكن ربطها بـ Backend + Vector DB + LLM حقيقي.
